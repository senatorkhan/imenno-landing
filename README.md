# Именно

Лендинг сервиса персонального подбора подарков с интерактивными коробками, демо подбора и формой уведомления о запуске.

## Открыть лендинг

Откройте `index.html` в браузере. Страница включает шрифты, изображения и скрипты и работает без сборки. В этом режиме пробная заявка сохраняется в браузере.

## Собрать после правок

Шаблон, скрипты и изображения находятся в `src/`. Для сборки нужен Python 3. Выполните из корня репозитория

```sh
python3 build.py
```

Команда пересоберёт `index.html` из исходников.

## Проверить форму с локальной базой

```sh
python3 imenno-server.py
```

Откройте [локальный предпросмотр](http://127.0.0.1:5818/). Сервер сохраняет адреса в локальный SQLite-файл `.imenno-waitlist.sqlite3`. Порт и путь к базе можно задать через `--port` и `--database`.

Лицензии шрифтов Prata и Golos Text приведены в [FONT-LICENSES.txt](FONT-LICENSES.txt).
